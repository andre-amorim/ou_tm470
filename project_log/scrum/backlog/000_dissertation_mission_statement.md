## Mission Statement
This project is the final **Graduation Capstone and Dissertation** for the Open University TM470 module. 

### Core Objectives:
1. **Academic Rigor:** Every technical increment must be documented to support the final dissertation narrative.
2. **Reproducibility:** The environment (Nix/uv) must be robust enough for external assessment.
3. **Traceability:** The Scrum log (this directory) provides empirical evidence of an Incremental SDLC.
4. **Innovation:** Research into OER (OU-XML) and automated XSLT workflows must demonstrate advanced computing skills.

## Macro Vision
To create a functional, visually interactive prototype of a didactic laboratory that transforms complex OU-XML schemas into student-friendly, interactive Markdown content.
