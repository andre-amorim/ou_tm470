# Prompt: The Declarative Hierarchy (Nix & uv)

## 🎨 Visual Concept
Create a high-resolution, technical illustration for **Unit 2: The Practice Object**. The style should be "Architectural Blueprint" meets "Modern Glass UI." It needs to visualize the relationship between the host system, the Nix Flake, and the uv-managed Python environment.

## 🏛️ Composition Layout
- **Background:** A deep midnight-blue technical grid (reminiscent of CAD software).
- **Core Subject:** A 3D isometric stack of translucent, glowing "Glass Bricks."
    - **Bottom Layer (The Host):** A solid, greyed-out foundation representing the user's laptop (MacBook/Chromebook). It should look "fixed" and unchanging.
    - **Middle Layer (The Nix Flake):** A vibrant, blue-glowing transparent layer that sits *above* the host. Inside this brick, show "Smart Icons" for `bash`, `openssl`, and `python`. Labels should read "Hermetic Foundation."
    - **Top Layer (The uv Environment):** A smaller, emerald-green glowing brick nested inside the Nix layer. It contains Python-specific symbols (`uv`, `pip`, `requests`). Label: "Project Specialist."
- **Interaction:** Show a series of "Data Fibres" connecting a code file labeled `flake.nix` into the bricks, suggesting that the code is *powering* the environment.

## 💡 Aesthetic Details
- **Colors:** Nix Blue (#5277C3), Emerald Green (#10B981), Graphite Grey.
- **Lighting:** Soft bloom effects on the glowing bricks. The green brick should feel "warm" and inviting, as it's the space where the developer works.
- **Atmosphere:** Clean, professional, and stable. No "digital noise" or "chaos"—this image represents the *solution* to the chaos of Unit 1.

## 📝 Text Overlays (Optional)
- Title: "The Declarative Hierarchy"
- Subtitle: "Encapsulating content and process as objects." (Reference: Bill Tait)
