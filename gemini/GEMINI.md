# Gemini CLI Exploration & Learning

This repository is dedicated to exploring and mastering the Gemini CLI, leveraging its advanced capabilities for collaborative software engineering and project management.

## Project Vision

To build a high-performance virtual team within the Gemini CLI environment to research, develop, and manage complex tasks efficiently.

## Core Resources

- **Official Documentation:** [Gemini CLI Docs](https://github.com/google-gemini/gemini-cli/tree/main/docs)
- **Experimental Features:**
    - **Agent Skills:** Utilizing `activate_skill` to enhance capabilities.
    - **Sub-agents:** Leveraging specialized agents like `codebase_investigator` and `cli_help`.

## Virtual Team Personas

The project operates through a structured team of AI personas, each with distinct responsibilities:

| Persona | Role & Focus |
| :--- | :--- |
| **Project Sponsor** | Defines high-level goals, provides resources, and ensures strategic alignment. |
| **Project Manager** | Orchestrates tasks, manages the implementation plan, and tracks progress (Conductor). |
| **Researcher** | Gathers information, analyzes documentation, and investigates technical possibilities. |
| **Developer** | Implements code, writes tests, and ensures technical excellence following project standards. |
| **Stakeholder** | Provides requirements, reviews outcomes, and ensures the project meets user needs. |

## Learning Roadmap

1. **Foundations:** Master basic CLI commands and file operations.
2. **Skill Integration:** Experiment with `activate_skill` (e.g., `skill-creator`).
3. **Sub-agent Orchestration:** Utilize `codebase_investigator` for deep repository analysis.
4. **Persona-driven Workflows:** Implement workflows where different personas collaborate on a single goal.
5. **Dendritic Nix Integration:** Apply Nix flakes for reproducible environments.

## Development Environment

- **OS:** Linux
- **Package Manager:** `uv` (Python), Nix (System)
- **Workflow:** Iterative development with integrated testing and documentation.
